# freehire.me

Reviewed 2026-11-02. New distinct platform, **free personal API, commercial publication requires paid plan**.

[Official API product documentation](https://freehire.me/jobs-api) documents `https://freehire.me/api/v1/jobs/search`, full Markdown descriptions, employer ATS links, location filters, and distinct posted/first-seen/last-seen/closed fields. Up to 100 postings are returned per page. Anonymous access is currently limited to 120 requests/minute and 2,000/day; it is expressly for personal and noncommercial use. A commercial job board requires an API plan, currently $29/month; the higher-volume Data plan is $99/month.

Therefore this is **not a free production source for ApplySmooth**. No API probe, account, payment, or adapter was made after finding the clear commercial-license boundary. Publisher-wide inventory claims are not live sampled/accepted US counts. Original-description/date parity was not tested.

Recommendation: exclude from the requested free-source implementation queue. Reconsider only if the scope changes to paid APIs or the publisher later offers a free commercial-display license. Do not mistake a working anonymous endpoint or open-source client code for commercial data-republication permission.
